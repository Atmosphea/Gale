## PLANS

### P1. Draggable reading marker (todo 134)
Tap-and-drag anywhere on the text column moves the *reading position container* (not the scroll) so the current word/line marker follows the finger. Implementation: pointerdown on content sets `_markerDrag`; pointermove translates `_contentEl` by dy and live-computes which line/word is under the center; on release, commit that gi via the existing `jumpToChapterGi`-style snap (rebuild window if out of range), then ease transform back to 0. Works in play (pause-resume seamlessly via `_runGen`) and pause. The virtualized window already keeps ±350 words mounted so out-of-bounds words exist during the drag; extend `renderWords` margin during drag to avoid clipping.

### P2. Index rework (todos 135, 136, 150, 151)
- **Bare word**: strip pill container; the word "INDEX" only, opacity driven by `tickMenuFade` alongside menu; tapping word or menu wakes it. Fix opening: the tap target currently sits under the content's pointer handlers on mobile — raise z-index and enlarge hit area (44px min).
- **Fancy build-in**: chapters cascade in letter-fade like the planned column-expand animation; center chapter first, neighbors staggered outward (already windowed 13).
- **Detection**: extend `buildReading` heading classifier: front/back-matter words (preface, foreword, prologue, epilogue, introduction, appendix, afterword, acknowledgments) = chapters. Roman numerals & "Part N" = top-level; numbered sub-sections (1.1, short caps lines following a chapter) = subchapters `level:2`, indented in index + smaller in reader. Index shows *numbers only* for numbered chapters (strip the word "Chapter").
- **Import metadata (151)**: EPUB — parse `toc.ncx` (`navMap/navPoint`, nested = subchapters) or EPUB3 `nav.xhtml` (`<nav epub:type="toc">` nested `<ol>`); map hrefs → spine items → word offsets at parse time. PDF — `pdf.getOutline()` gives a nested outline with destinations; resolve each dest to a page index → nearest word offset. Both offline (already-bundled jszip/pdf.js). Fall back to text heuristics only when no metadata exists. Store `chapters: [{title, gi, level}]` on the book.
- **Live preview while scrolling (150)**: FEASIBLE — see answer in chat. Render the centered chapter's first ~80 words into a ghost pane while the index is open; the paragraphs array is already in memory, so it's a slice + join (sub-ms), no DOM churn beyond one text node swap per scroll step. Full window rebuild only on commit (tap).

### P3. WPM/LPM persistence (137)
`saveSettings` already persists a settings bag; add `speed` + `lpm` to it and restore in constructor (currently seeded from config/wpm test only). Per-book place already stores mode; WPM/LPM become global.

### P4. Button swaps + icons (138)
Swap positions of highlight-cycle and next-paragraph in the bottom bar. New highlight icon: a rounded-rect "marker over text-line" glyph (3 lines with the middle one boxed) instead of current abstract mark.

### P5. TTS v3 (139)
- Speak *lines* in scroll/sentence modes (one utterance per line = smooth prosody), *words* in word/river.
- Voices: (0) Native premium — prefer `localService` voices, rank Siri/Samantha/Daniel; rate mapped to WPM. (1) SAM formant synth (exists). (2) "Choir" — WebAudio additive vowel pads (formant tables per vowel, portamento between syllables). (3) "Whisper" — filtered-noise consonant + sine vowel skeleton, very light. All in-code, offline. Pre-warm `getVoices()` at mount; queue with ≤1 pending utterance; cancel only on mode/voice change.

### P6. Capsule image persistence (140)
Covers currently pass through image-slot sidecar (project-local). For sessions: store cover dataURL under `rv_cover_<bookId>` in localStorage at drop time (already done for EPUB-extracted covers via `book.cover`); rehydrate in `buildCapsule`. Audit the double-tap upload path to write the same key.

### P7. Column-expand text with no reflow (141)
Pre-render the expanded-state text block (title, author, stats) inside every column at final geometry, `opacity:0`, `pointer-events:none`. On expand, no layout change — only per-letter opacity fade-in ordered from the center letter outward (`transition-delay = |i - mid| * stagger`). Title/stats split into letter spans at render time (cheap; ≤80 letters).

### P8. Title typography system (142)
`layoutTitle(title, seed)` → deterministic-from-seed layout: tokenize; classify words (stop-words the/of/and/a → tiny, 3–5-letter feature words → own line filling width, long words → width-fill sizing via measured glyph width). Positions: stop-words may sit between lines, superscript at cap-height, or on the baseline gap of neighbors. Compute in a fixed-size box with binary-search font sizing so nothing clips. Swipe on title → `seed++` → animated re-layout (FLIP transitions per word). Used in capsule preview + reader title. All constraints (min/max scale, stop-word list, line gap) in config `titleArt`.

### P9. Motion Cue layer, full architecture (143, 144)
Standalone module-in-class: `MotionCue` object with `attach(source)`, `setParams({gain,damping,deadZone,maxOpacity,...})`, `kill()`. Pipeline stubs: `ingest(sample)` → low-pass filter → complementary-filter fusion slot (accel+gyro; Kalman-ready interface) → gravity compensation slot → motion classifier state machine (IDLE/HUMAN/VEHICLE; only VEHICLE renders) → dead-zone → temporal interpolation buffer read by rAF (VSync-bound) → symmetric clamped displacement. Config: `patternBreak.motion.dots` = explicit array of `{x,y,anchor}` dot positions + count; corner/mid presets. DeviceMotion hookup deferred (permission prompt + `devicemotion` listener behind a flag), CoreMotion mapping documented for the iOS wrapper.

### P10. Antikythera fidget (145)
Three interlocked SVG gears (ratios 1 : -2/3 : 5/4 — plausible antikythera-style trains), full circles, bronze-tone strokes, spokes + hub detail. Drag any gear; others rotate by ratio. Per-gear detents at tooth pitch → `navigator.vibrate` patterns of different intensity (5ms / 12ms / 25ms) per gear. Draggable container (pointer-drag repositions, persisted). In Manual mode, primary gear detents call `stepWord(±1)`/line. Sits below menu, z-above content.

### P11. Menu glassmorphism v3 (146)
Same bevel vocabulary as capsules: 1px inner top highlight (inset 0 1px rgba(255,255,255,.25)), inner bottom shade, drop shadow, and a *bottom-edge reflection*: an absolutely-positioned 8px strip at the inset bottom showing the page background `background-attachment`-style (scaled + flipped + blurred backdrop slice), masked with a feather. All knobs in `config.glass`.

### P12. Chapter headings in reader + haptics (147, 153)
`buildReading` marks heading paragraphs; render them at 1.6em Odenburgh with space above. Crossing one during playback triggers the chapter haptic: `navigator.vibrate([8,30,12,30,18,30,90])` — building pulses then a settling thunk (page-turn feel) — plus existing chapter sound. New **Haptics** toggle button above Fade in the aids grid (state `hapticsOn`, persisted).

### P13. Chapter swipe navigation (148)
Horizontal swipe in reader (non-river) → next/prev chapter. Exit: current mounted lines cascade out leftward, word-by-word (per-word delay by line then column). Enter: new chapter's first 3–5 lines cascade in right→left with fade. Reuse window rebuild from `jumpToChapterGi`; animation via per-word `transition-delay` on transform+opacity, two rAF passes.

### P14. Pattern breaks (149, 152, 154)
- **Snooze (149)**: new cycle entry. Every N minutes a bubble (capsule-circle: same glass bevel) fades in at the rail bottom and rises 3s to a random height on a fixed vertical rail; when it stops, playback pauses (soft chime). Tap = pop animation + resume. Untapped = stays paused forever (sleep-safe). Config: interval, riseMs, rail x-position.
- **Period (152)**: reduce flicker count 4→2, intensity .9→.45, every 2nd→every 4th sentence.
- **Motion (154)**: make dots breathe (slow radius pulse), drift on lissajous idle path, glow on displacement, and add a faint connecting arc between mid dots — peripheral but alive.

### P15. Index live-preview feasibility (answered in chat)
Yes — paragraphs are in memory; rendering the centered chapter's opening text while scrolling is a sub-millisecond string slice; keep one ghost element and swap textContent per index step. 20 chapters/sec is trivial (no window rebuild until commit).
